Começar

Antes de tudo: o que são HTML e CSS?

Um site tem duas partes. Pense em uma casa:

🧱 HTML

É a estrutura: o que existe na página (títulos, textos, fotos, links). Como as paredes e os cômodos.

🎨 CSS

É a aparência: cores, tamanhos, posição. Como a pintura e a decoração.

O HTML é feito de tags. Quase toda tag abre e fecha, e o conteúdo fica no meio:

<p>Olá, mundo!</p>
abre a tagconteúdofecha a tag (tem uma barra /)
O que você precisa: um computador, o Bloco de Notas (ou o Visual Studio Code, que é melhor), um navegador e uma conta gratuita no GitHub.

Mãos à obra

1

Crie a pasta do site

Crie uma pasta chamada meu-site. Dentro dela ficarão todos os arquivos. Por enquanto, coloque nela uma foto sua com o nome foto.png.

meu-site/ 
meu-site/
├── foto.png
├── index.html     (vamos criar)
└── style.css      (vamos criar)

Crie um arquivo de texto e salve como index.html. O nome index é especial: é a página inicial do site.

2

Escreva o esqueleto da página

Toda página HTML começa assim. Copie e salve:

index.html 
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Meu Portfólio</title>
</head>
<body>

</body>
</html>
  • <!DOCTYPE html>Avisa o navegador: “isto é uma página HTML moderna”.
  • <html lang="pt-BR">Envolve a página toda e diz que o idioma é português do Brasil.
  • <head>A “cabeça”: informações que não aparecem na tela.
  • charset="utf-8"Faz acentos e ç aparecerem certinho.
  • name="viewport"Faz o site se ajustar à tela do celular. Não esqueça!
  • <title>O nome que aparece na aba do navegador.
  • <body>O “corpo”: tudo o que você escrever aqui aparece na tela.
Teste: dê dois cliques no arquivo. Ele abre no navegador. A página está em branco, e isso é o esperado.
3

Coloque título e texto

Escreva isto entre <body> e </body>:

index.html 
<h1>Seu Nome</h1>
<h2>Desenvolvedor(a) de Software</h2>
<p>Olá! Estou aprendendo a criar sites.</p>
  • <h1>Título principal. Use só um por página.
  • <h2>Subtítulo, um pouco menor. Existem também h3, h4…
  • <p>Parágrafo de texto (de paragraph).

Salve e aperte F5 no navegador para ver a mudança. Faça isso depois de cada passo.

4

Adicione sua foto e um link

Coloque a foto acima do <h1> e o link abaixo do parágrafo:

index.html 
<img src="foto.png" alt="Minha foto">

<a href="https://github.com/SEU-USUARIO">Meu Github</a>
  • <img>Mostra uma imagem. Não tem tag de fechamento.
  • src="foto.png"Qual arquivo mostrar (o nome da sua foto).
  • alt="..."Descrição da imagem, lida por quem não enxerga a tela.
  • <a href="...">Cria um link. O href é o endereço de destino, e o texto no meio é o que a pessoa clica.
5

Crie o menu

Logo depois de <body>, antes da foto, escreva:

index.html 
<nav>
  <a href="index.html">Sobre mim</a>
  <a href="project.html">Projetos</a>
  <a href="contact.html">Contato</a>
</nav>

<nav> (de navigation) é a “caixa” do menu. Dentro dela ficam os links para as 3 páginas.

Crie as outras páginas: copie o index.html duas vezes e renomeie as cópias para project.html e contact.html. Em cada uma, troque o título e o texto. O menu continua igual.
6

Ligue o CSS e escolha as cores

Primeiro, avise o HTML que existe um arquivo de estilo. Dentro do <head>, depois do <title>:

index.html 
<link rel="stylesheet" href="style.css">

Agora crie o arquivo style.css na mesma pasta e escreva:

style.css 
body {
  background: #fbf7f0;
  color: #2b2118;
  font-family: Georgia, serif;
}
  • bodyO seletor: diz quem vai receber o estilo (aqui, a página toda).
  • { ... }As chaves guardam as regras.
  • background: #fbf7f0;Uma regra: propriedade (cor de fundo), dois-pontos, valor e ponto e vírgula.
  • colorA cor do texto.
  • font-familyO tipo de letra.
Os códigos como #fbf7f0 são cores. Para escolher as suas, procure “seletor de cores” no Google.
7

Centralize e deixe a foto redonda

Adicione no style.css:

style.css 
body {
  max-width: 700px;
  margin: 0 auto;
  padding: 20px;
  text-align: center;
}

img {
  width: 150px;
  height: 150px;
  object-fit: cover;
  border-radius: 50%;
}

Você pode escrever o body duas vezes, mas o ideal é juntar tudo na mesma chave. Cole as novas linhas dentro do body que você já tem.

  • max-width: 700pxO conteúdo nunca passa de 700 px de largura, para não ficar esticado em telas grandes.
  • margin: 0 autoEmpurra o conteúdo para o centro da tela.
  • padding: 20pxEspaço interno, para o texto não colar na borda.
  • text-align: centerCentraliza os textos.
  • border-radius: 50%Arredonda as bordas. Com 50% e uma imagem quadrada, vira um círculo.
  • object-fit: coverCorta a foto para preencher o círculo sem deformar.
8

Coloque o menu em linha

style.css 
nav {
  display: flex;
  justify-content: center;
  gap: 20px;
}

a {
  color: #a8501c;
}
  • display: flexLiga o Flexbox: os itens da caixa ficam lado a lado, em vez de um embaixo do outro.
  • justify-content: centerCentraliza os itens na linha.
  • gap: 20pxEspaço entre os itens.
  • a { color }Muda a cor de todos os links.

9

Faça o site funcionar no celular

“Responsivo” quer dizer que o site se adapta a qualquer tela. Você já fez a maior parte: a linha viewport do passo 2 e o max-width do passo 7. Para ajustar telas maiores, adicione no final do style.css:

style.css 
@media (min-width: 768px) {
  img {
    width: 220px;
    height: 220px;
  }
}
  • @media“Só aplique o que está dentro se…”
  • (min-width: 768px)…a tela tiver pelo menos 768 px de largura (tablet ou computador).

Ou seja: no celular a foto tem 150 px, e em telas maiores ela cresce para 220 px. Para testar no computador, aperte F12 e use o ícone de celular, ou diminua a largura da janela.

10

Coloque o site no ar

  1. Entre em github.com e crie um repositório novo (New repository) chamado meu-site, marcado como Public.
  2. Clique em uploading an existing file e arraste todos os arquivos da pasta (index.html, project.html, contact.html, style.css e a foto). Depois clique em Commit changes.
  3. Vá em Settings → Pages. Em Branch, escolha main e a pasta / (root). Clique em Save.
  4. Espere alguns minutos. Seu site fica em https://SEU-USUARIO.github.io/meu-site/.
Parabéns! Seu site está publicado. Para mudar algo, edite o arquivo e envie de novo para o GitHub.
