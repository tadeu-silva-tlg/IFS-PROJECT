Começar

Antes de tudo: o que são HTML e CSS?

Um site tem duas partes. Pense em uma casa:

🧱 HTML

É a estrutura: o que existe na página (títulos, textos, fotos, links). Como as paredes e os cômodos.

🎨 CSS

É a aparência: cores, tamanhos, posição. Como a pintura e a decoração.

O HTML é feito de tags. Quase toda tag abre e fecha, e o conteúdo fica no meio:

<p>Olá, mundo!</p>
abre a tagconteúdofecha a tag (tem uma barra /)

No fim dos 10 passos, seu site terá este formato:

Mãos à obra

1

Crie a pasta e organize os arquivos

Você está aqui: ainda não aparece nada na tela. Estamos só preparando a pasta e os arquivos.

Crie uma pasta chamada meu-site. Dentro dela, crie outra pasta chamada img e coloque lá duas imagens: o logo, com o nome logo.png, e uma foto para o fundo, com o nome fundo.jpg.

meu-site/ 
meu-site/
├── img/
│   ├── logo.png     (o logo, de preferência quadrado)
│   └── fundo.jpg    (a foto de fundo)
├── index.html       (vamos criar)
└── index.css        (vamos criar)

Crie dois arquivos de texto vazios e salve como index.html e index.css. O nome index é especial: é a página inicial do site. A pasta img mantém as imagens organizadas.

2

Escreva o esqueleto da página

MenuTítuloSubtítuloConteúdoRodapé

Você está aqui: na página inteira, ainda em branco. Só existe o esqueleto do HTML.

Toda página HTML começa assim. Copie e salve no index.html:

index.html 
<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Meu Site</title>
    <link rel="stylesheet" href="./index.css">
</head>

<body>

</body>
</html>
  • <!DOCTYPE html>Avisa o navegador: “isto é uma página HTML moderna”.
  • <html lang="pt-BR">Envolve a página toda e diz que o idioma é português do Brasil.
  • <head>A “cabeça”: informações que não aparecem na tela.
  • charset="UTF-8"Faz acentos e ç aparecerem certinho.
  • name="viewport"Faz o site se ajustar à tela do celular. Não esqueça!
  • <title>O nome que aparece na aba do navegador.
  • <link ... href="./index.css">Liga o arquivo de estilo ao HTML. O ./ significa “nesta mesma pasta”.
  • <body>O “corpo”: tudo o que você escrever aqui aparece na tela.
Teste: dê dois cliques no arquivo. Ele abre no navegador. A página está em branco, e isso é o esperado.
3

Crie a caixa da página e o menu

MenuTítuloSubtítuloConteúdoRodapé

Você está aqui: no menu, o link “Início” no topo da página.

Dentro do <body>, escreva:

index.html 
<div class="box">

    <nav>
        <ul>
            <li>
                <a href="index.html">Início</a>
            </li>
        </ul>
    </nav>

</div>
  • <div class="box">Uma caixa sem significado próprio, usada para agrupar coisas. O class="box" é um “apelido” que o CSS usará depois para dar espaço nas laterais. Ela vai envolver a página inteira.
  • <nav>De navigation: a área do menu.
  • <ul> e <li>Uma lista sem numeração e cada item dela. É assim que se monta um menu.
  • <a href="index.html">Cria um link. O href é o destino (aqui, a própria página inicial).
Nos próximos passos, escreva o novo código dentro da div, antes do </div> final. Se criar mais páginas um dia, é só adicionar mais itens <li> ao menu.
4

Monte o cabeçalho: título, logo e subtítulo

MenuTítuloSubtítuloConteúdoRodapé

Você está aqui: no cabeçalho: o título, o logo redondo e o subtítulo.

Logo depois do </nav>, escreva:

index.html 
<header>
    <h1>Título do Site</h1>

    <div class="center">
        <img src="./img/logo.png" alt="Meu logo">
    </div>

    <h2>Subtítulo do Site</h2>
</header>
  • <header>O cabeçalho da página: a parte de apresentação, no topo.
  • <h1>O título principal. Use só um por página.
  • <div class="center">Outra caixa. O apelido center servirá para centralizar a imagem.
  • <img>Mostra uma imagem. Não tem tag de fechamento.
  • src="./img/logo.png"O caminho da imagem: dentro da pasta img, o arquivo logo.png.
  • alt="Meu logo"Descrição da imagem, lida por quem não enxerga a tela.
  • <h2>Subtítulo, menor que o h1.
5

Escreva o conteúdo principal

MenuTítuloSubtítuloConteúdoRodapé

Você está aqui: no conteúdo principal: as seções de texto no meio da página.

Depois do </header>, escreva as seções de texto. O HTML tem títulos de h1 (o maior) até h6 (o menor). Este site usa até o h5:

index.html 
<main>
    <section>
        <h3>Sobre mim</h3>
        <p>Escreva aqui quem você é.</p>

        <h4>Meu projeto</h4>
        <p>Escreva aqui sobre o seu projeto.</p>

        <h5>Meu objetivo</h5>
        <p>Escreva aqui o objetivo do site.</p>
    </section>
</main>
  • <main>O conteúdo principal da página. Só existe um por página.
  • <section>Uma seção: um grupo de assuntos que andam juntos.
  • <h3> <h4> <h5>Subtítulos, cada um menor que o anterior. Organizam o texto em partes.
  • <p>Parágrafo de texto (de paragraph).

Salve e aperte F5 no navegador para ver a mudança. Faça isso depois de cada passo.

6

Crie o rodapé e feche a caixa

MenuTítuloSubtítuloConteúdoRodapé

Você está aqui: no rodapé, a parte final da página, com os contatos.

Depois do </main>, ainda dentro da div, escreva:

index.html 
<footer class="rodape">
    <div class="container">
        <div class="coluna">
            <p>Email: seuemail@exemplo.com</p>
            <p>Telefone: (00) 00000-0000</p>
        </div>
    </div>

    <div class="direitos">
        <p>© 2026 Seu Nome - Todos os direitos reservados</p>
    </div>
</footer>

<footer> é o “rodapé”: a parte final da página, com contatos e direitos autorais. Dentro dele, as caixas container, coluna e direitos separam os contatos dos direitos autorais. Troque os dados de exemplo pelos seus.

Pronto o HTML! Confira se o </div> da caixa box vem logo depois do </footer>. A página já tem todo o conteúdo, mas está “crua”: fundo branco e letras pretas. O CSS dá a aparência nos próximos passos.
7

Crie o CSS: fundo e letras

MenuTítuloSubtítuloConteúdoRodapé

Você está aqui: no fundo da página inteira e na cor das letras.

Abra o arquivo index.css e escreva:

index.css 
:root {
    --cor-destaque: #ff9d2e;
}

body {
    background-color: black;
    background-image: url('./img/fundo.jpg');
    background-repeat: no-repeat;
    background-size: cover;
    color: white;
    font-family: Arial, sans-serif;
}
  • :rootGuarda valores com nome. Aqui, a --cor-destaque: mude a cor neste único lugar e ela muda em todo o site.
  • bodyO seletor: diz quem vai receber o estilo (aqui, a página toda).
  • { ... }As chaves guardam as regras. Cada regra é propriedade: valor;.
  • background-color: blackCor de fundo preta. Aparece se a imagem não carregar.
  • background-image: url(...)Coloca a foto da pasta img como fundo.
  • background-repeat: no-repeatNão repete a foto como azulejos.
  • background-size: coverEstica a foto para cobrir a tela toda.
  • color: whiteDeixa as letras brancas, para aparecerem no fundo escuro.
  • font-familyO tipo de letra.
O site do exemplo usa uma foto azul escura de fundo. Escolha uma foto escura, para as letras brancas continuarem legíveis.
8

Estilize o menu e a caixa

MenuTítuloSubtítuloConteúdoRodapé

Você está aqui: de volta ao menu, agora com aparência, e no espaço das laterais da página.

Adicione no index.css:

index.css 
ul {
    display: flex;
    justify-content: space-between;
    list-style: none;
    align-items: center;
    padding: 16px;
    font-size: large;
}

a {
    color: white;
    text-decoration: none;
}

nav a:hover {
    color: var(--cor-destaque);
}

.box {
    padding: 0px 50px;
}
  • display: flexLiga o Flexbox: os itens da lista ficam lado a lado, em vez de um embaixo do outro.
  • justify-content: space-betweenEspalha os itens: o primeiro vai para a esquerda e o último para a direita. Com um só item, ele fica à esquerda.
  • list-style: noneTira as bolinhas da lista.
  • align-items: centerAlinha os itens ao centro, na vertical.
  • padding: 16pxEspaço interno de 16 px.
  • font-size: largeLetras maiores.
  • a { ... }Links brancos e sem sublinhado.
  • nav a:hoverSó os links do menu, quando o mouse passa por cima: ganham a cor de destaque.
  • .boxO ponto . significa “o que tem class="box"”. Dá 50 px de espaço nas laterais da página.
9

Estilize título, logo e rodapé

MenuTítuloSubtítuloConteúdoRodapé

Você está aqui: no título, no logo, no subtítulo e no rodapé.

Adicione no final do index.css:

index.css 
h1 {
    display: flex;
    justify-content: center;
    color: white;
}

.center {
    text-align: center;
}

img {
    width: 250px;
    height: 250px;
    border-radius: 50%;
    border: 5px solid var(--cor-destaque);
}

h2 {
    color: var(--cor-destaque);
}

footer {
    display: flex;
    justify-content: center;
    padding: 50px;
    margin: 40px;
}

footer p {
    margin: 20px;
}
  • h1 { display: flex; justify-content: center }Centraliza o título, usando o Flexbox.
  • .center { text-align: center }Centraliza o que está na caixa center: o logo.
  • width / height: 250pxO logo fica com 250 px de largura e de altura. Use uma imagem quadrada, para não deformar.
  • border-radius: 50%Arredonda as bordas. Em uma imagem quadrada, vira um círculo.
  • border: 5px solid var(--cor-destaque)Uma borda de 5 px, na cor de destaque, ao redor do logo.
  • h2 { color: var(--cor-destaque) }Pinta o subtítulo com a cor de destaque.
  • footer { display: flex ... }Centraliza o conteúdo do rodapé e cria espaços ao redor (padding por dentro, margin por fora).
  • footer pSó os parágrafos que estão dentro do rodapé: ganham 20 px de espaço ao redor.
Extra para o celular (opcional): o CSS acima usa tamanhos fixos, então em telas bem pequenas o logo e o rodapé podem ficar apertados. Para melhorar, adicione no final do arquivo: 
@media (max-width: 600px) {
    .box { padding: 0 20px; }
    img { width: 180px; height: 180px; }
    footer { margin: 20px 0; padding: 20px; }
}
@media (max-width: 600px) quer dizer: “só aplique o que está dentro se a tela tiver até 600 px de largura”, ou seja, no celular. Teste apertando F12 e usando o ícone de celular.
10

Coloque o site no ar

MenuTítuloSubtítuloConteúdoRodapé

Você está aqui: no site completo, pronto para o mundo ver.

  1. Entre em github.com e crie um repositório novo (New repository) chamado meu-site, marcado como Public.
  2. Clique em uploading an existing file e arraste os arquivos da pasta: index.html, index.css e a pasta img inteira, com o logo e o fundo. Depois clique em Commit changes.
  3. Vá em Settings → Pages. Em Branch, escolha main e a pasta / (root). Clique em Save.
  4. Espere alguns minutos. Seu site fica em https://SEU-USUARIO.github.io/meu-site/.
Parabéns! Seu site está publicado. Se as imagens não aparecerem, confira se os nomes dos arquivos na pasta img são exatamente os mesmos do código (o GitHub diferencia maiúsculas de minúsculas).

Deixe com a sua cara

O código dos 10 passos é um modelo base: tem o mesmo formato do nosso exemplo (menu, logo redondo, textos e rodapé), mas é todo seu para mudar.

✏️ Textos

Troque os títulos, os parágrafos e os dados do rodapé pelos seus.

🎨 Cores

Mude a --cor-destaque no início do CSS, e o site inteiro acompanha.

🖼️ Imagens

Substitua logo.png e fundo.jpg na pasta img, mantendo os nomes.

🔗 Menu

Adicione novos itens <li> com links para outras páginas que criar.
